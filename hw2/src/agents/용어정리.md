## 1. 일상 비유로 이해하는 6장 & 7장 핵심 개념

### 🎬 6장: 정책 경사 (Policy Gradients) — *"오디션 프로그램의 신인 발굴"*
모방학습과 달리 강화학습에는 전문가 시연(정답)이 없습니다. 무작정 무대에 올라가 춤을 춰보고, 관객의 반응(보상)에 따라 다음 행동을 고쳐 나가는 과정입니다.

* **$\tau$ (타우, 궤적)**: 무대 위에서 참가자가 보여준 **'처음부터 끝까지의 공연 기록(상태와 행동의 흐름)'**입니다.
* **로그 미분 트릭 (Log-Derivative Trick)**: 
  * 무대 뒤의 복잡한 물리 법칙(환경의 전이 확률)을 전혀 몰라도, **"이번 공연 점수가 좋았는지 나빴는지"** 결과만 알면 어떤 동작의 확률을 높여야 할지 역추적할 수 있게 해주는 수학적 마법입니다.
* **인과성 (Reward-to-go / 앞뒤 분리하기)**: 
  * 오디션 후반부에 음을 이탈해 탈락했다고 해서, 시작할 때 멋지게 부른 첫 소절까지 벌을 주면 억울합니다. **"내가 그 행동을 한 *이후*에 벌어진 보상만 내 책임이다"**라고 시점을 자르는 트릭입니다.
* **기준선 (Baseline, $b$ / 평균치)**: 
  * 참가자 평균 점수가 80점일 때 내가 85점을 받았다면, **"평균보다 5점 더 잘했네!"**라고 평가해야 진짜 실력이 보입니다. 전체 평균을 빼주어 학습의 흔들림(분산)을 줄입니다.

### 🎭 7장: 액터-크리틱 (Actor-Critic) — *"영화 촬영 현장의 감독과 배우"*
공연이 끝날 때까지 기다렸다가 한 번에 점수를 매기면 시간이 오래 걸리고 흔들림(분산)이 큽니다. 촬영 현장에 **전문 평론가(크리틱)**를 상주시켜 실시간으로 피드백을 받는 구조가 액터-크리틱입니다.

* **액터 (Actor)**: 열심히 연기(행동)를 하는 **배우(정책 신경망 $\pi_\theta$)**입니다.
* **크리틱 (Critic)**: 옆에서 대본을 쥐고 지켜보며 **"방금 그 표정 평균 이상이야!"** 하고 실시간으로 상태의 가치를 평가해 주는 **감독(가치 신경망 $V_\phi$)**입니다.
* **부트스트랩 (Bootstrapping)**: 
  * 영화가 끝날 때까지 몇 달을 기다리지 않고, 매 장면마다 **"지금 당장 얻은 보상 + 앞으로의 예상 점수($r + \gamma V$)"**를 합쳐 실시간 피드백을 주는 기법입니다. (벨만 방정식의 씨앗)
* **$\gamma$ (감마, 할인율)**: 
  * **"미래의 성공이 중요할까, 당장 코앞의 성공이 중요할까?"**를 조절하는 손잡이입니다 ($0 \le \gamma < 1$). $\gamma = 0.99$라면 약 $1/(1-\gamma) = 100$스텝 앞의 미래까지 내다보며 장기 계획을 세웁니다.
* **$\lambda$ (람다, GAE의 조절 손잡이)**: 
  * 감독의 피드백을 얼마나 넓은 범위의 장면에 걸쳐 반영할지 정하는 조절 손잡이입니다. $0$에 가까우면 바로 다음 컷만 보고(편향↑, 분산↓), $1$에 가까우면 전체 흐름을 봅니다(편향↓, 분산↑).

## 2. 파이썬 구현 코드 핵심 구조 및 용어 정리

### 📌 주요 용어 딕셔너리
| 용어 / 변수 | 기호 | 의미 및 역할 |
| :--- | :---: | :--- |
| **델타 (TD Error)** | $\delta_t$ | "내가 예상했던 가치"와 "실제 받은 보상 + 다음 상태의 예상 가치" 사이의 **1스텝 오차** ($r_t + \gamma V(s_{t+1}) - V(s_t)$) |
| **어드밴티지 (Advantage)** | $A(s, a)$ | 이 행동이 현재 상태에서 할 수 있는 평균적인 행동보다 **얼마나 더 우수했는가**를 나타내는 점수 |
| **터미널 (`terminals`)** | - | 에피소드(한 판)가 끝났는지 알려주는 신호 (`1`이면 판의 마지막 스텝, `0`이면 진행 중) |
| **GAE** | $\hat{A}^{GAE}$ | **Generalized Advantage Estimation**. 1스텝 오차($\delta$)들을 지수적으로 감쇠($\gamma\lambda$)시키며 미래부터 거꾸로 누적해, 편향과 분산의 균형을 맞춘 어드밴티지 추정법 |
| **LunarLander** | - | OpenAI Gym(Gymnasium)의 고전 강화학습 환경. 달착륙선의 엔진을 제어해 착륙 패드에 안전하게 안착시키는 물리 시뮬레이션 게임 |

### 🧩 전체 학습 파이프라인 흐름도

1. **데이터 수집 (`utils.py` - `sample_trajectories`)**
   * 에이전트가 환경에서 `env.step(ac)`을 반복하며 한 판(`sample_trajectory`)씩 경험(상태, 행동, 보상, 종료 여부)을 수집합니다.
   * 목표한 배치 크기(`min_timesteps_per_batch`)가 찰 때까지 여러 판을 모은 뒤, 신경망에 한 번에 넣기 위해 거대한 1차원 배열로 이어 붙입니다(`np.concatenate`).
2. **에이전트 업데이트 (`pg_agent.py` - `PGAgent.update`)**
   * **Step 1 (`_calculate_q_vals`)**: Reward-to-go 설정에 따라 각 스텝 이후로 받은 할인 보상 합을 계산합니다.
   * **Step 2 (`_estimate_advantage`)**: 크리틱이 예측한 가치 $V(s)$를 바탕으로 어드밴티지(또는 GAE)를 구하고, 학습 안정을 위해 평균 $0$, 표준편차 $1$로 정규화합니다.
   * **Step 3 (`self.actor.update`)**: 구한 어드밴티지를 가중치로 곱해 정책 경사($\nabla_\theta \log \pi_\theta \cdot A$) 방향으로 액터 신경망을 업데이트합니다.
   * **Step 4 (`self.critic.update`)**: 실제 얻은 보상 타깃과 크리틱의 예측값 사이의 MSE 오차(`F.mse_loss`)를 줄이도록 크리틱 신경망을 학습시킵니다.
3. **메인 실행 루프 (`run_hw2.py` - `run_training_loop`)**
   * 정해진 반복 횟수(`n_iter`) 동안 **[데이터 수집 $\rightarrow$ 에이전트 업데이트 $\rightarrow$ 성능 평가 및 로깅]** 사이클을 돌립니다.

### 🔍 핵심 코드 해부: GAE 역순 계산 루프 (`_estimate_advantage`)

```python
for i in reversed(range(batch_size)):
    # 1. 판이 계속되면 1, 판의 마지막 칸(terminals[i] == 1)이면 0
    not_done = 1 - terminals[i]
    
    # 2. δ (1스텝 TD 오차): 생각보다 얼마나 좋았는가?
    #    판이 끝났다면(not_done == 0) 다음 상태의 가치(values[i + 1])는 계산에서 차단함
    delta = rewards[i] + self.gamma * values[i + 1] * not_done - values[i]
    
    # 3. A (GAE 재귀 누적): 뒤에서부터 앞으로 오면서 미래의 오차들을 줄줄이 엮어서 쌓기
    advantages[i] = delta + self.gamma * self.gae_lambda * advantages[i + 1] * not_done
```

* **왜 `reversed`(거꾸로) 루프를 돌까요?**
  * 시점 $t$의 어드밴티지를 구하려면 미래 시점($t+1, t+2, \dots$)에서 발생한 오차($\delta$)들이 먼저 계산되어 있어야 하기 때문입니다. 맨 마지막 스텝부터 앞으로 거슬러 올라오며 `advantages[i + 1]` 값을 재활용해 한 번의 루프로 모든 스텝의 GAE를 깔끔하게 계산합니다.
